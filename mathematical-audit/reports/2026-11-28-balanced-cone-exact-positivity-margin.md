## POME-BALANCED-EXACT-TRACE-POSITIVITY-MARGIN-001

Low / verified conditional deduction (not a false printed statement). Source: docs/sections/balanced-forms-and-movable-classes/index.html, blob 626cf11270ca02d97f2ea1d784139a2b8a92ef19. Lemma 10.101.1 (source F9131705, permanent 255F6B93CCE9), physical lines 20–48; Proposition 10.101.2 (source D37F07A7, permanent 8DC16DCAD850), lines 53–70.

Let X be a connected compact Kähler n-fold, n>=2, and fix a Kähler form omega. Write H=[omega^(n-1)]. For any real (n-1,n-1) Bott–Chern class b, define

    m(b) = inf { <b,[T]_A> : T >= 0, dd^c T=0,
                                      integral T wedge omega^(n-1)=1 }.

This is a finite attained minimum. It equals

    sup { t in R : there is a smooth real closed representative
                     Gamma in b with Gamma > t omega^(n-1) }
  = sup { t in R : there is such a Gamma with Gamma >= t omega^(n-1) }.

In particular the set of strict admissible t is exactly (-infinity,m(b)).
For b balanced, for every 0<t<m(b), the representative can be chosen
Gamma=gamma^(n-1) for a balanced Hermitian metric gamma, by the positive root formula. No assertion of existence of an optimal smooth representative at t=m(b).

Proof. The trace-one positive pluriharmonic current set is nonempty (scale omega), weakly compact by the mass bound, and closed by continuity of dd^c and trace. Evaluation against a fixed smooth closed representative of b is continuous. This proves attainment and finiteness, using precisely the mass and pairing input of Lemma 10.101.1. For t<m(b), the class b-tH pairs strictly positively with all nonzero positive pluriharmonic currents, since their trace mass is positive. Lemma 10.101.1 gives a smooth closed strictly positive representative Q of b-tH. Set Gamma=Q+t omega^(n-1). Conversely if Gamma>=t omega^(n-1), pairing with each normalized current gives m(b)>=t. If the inequality is strict, compactness of X gives Gamma-t omega^(n-1)>=delta omega^(n-1) for some delta>0, so m(b)>=t+delta. Thus both suprema agree and the strict endpoint is excluded. If a smooth Gamma achieves the weak endpoint, every minimizing current annihilates the nonnegative form Gamma-m(b)omega^(n-1); this is a positive measure of total mass zero. In particular the current vanishes on the open locus where this form is strictly positive (locally bound below by a positive multiple of omega^(n-1)). This is a necessary condition, not a smooth existence claim.

The function m is concave, positively homogeneous, superadditive, and satisfies m(b+sH)=m(b)+s for every real s. All follow by taking the infimum of the linear trace-one pairings. More precisely define the seminorm p(d)=max_{T trace one}|<d,[T]_A>|. The compactness above gives finiteness and continuity in finite-dimensional cohomology. Comparing infima gives |m(b)-m(c)|<=p(b-c), with sharp coefficient one because p(sH)=|s|. By Lemma 10.101.1, b is balanced exactly when m(b)>0, and belongs to the closed balanced cone exactly when m(b)>=0. Conditional on Proposition 10.101.2 this also characterizes the movable cone and its interior. This is a margin for (n-1,n-1) classes, not an assertion about a (1,1) pseudoeffective threshold (the earlier POME-MOVABLE-DUAL-THRESHOLD-GAUGE-001 is distinct). The root construction supplies a bound for gamma^(n-1), not a bound for gamma itself in the same order.

Concrete check in dimension two: let X=P^1 x P^1, with pullback positive forms a,b of integral one, omega=a+b. For class s[a]+t[b], the smooth representative s a+t b is >=min(s,t) omega, while T=a and T=b are both trace-one closed positive currents and pair to t and s, respectively. Thus m=min(s,t) and the weak bound is attained here. This also verifies the normalization without invoking approximation.
